# Abdullah Farhat Khokhar | Portfolio

My portfolio, laid out like a desktop collaboration app: chats, activity, projects, experience and a contact form, all in one static page.

**Live:** https://abdullahkhokhar1.github.io/Portfolio/

- `index.html` is the complete site (generated).
- `src/` holds the sources: content in `data.js`, the app shell in `app.js`, the analytics and automation pages in `labs.js`, plus styles, markup and icons.
- `assets/` has images, logos and the résumé PDF.

To rebuild after editing `src/`, run `node build.cjs`.

Icons: Fluent UI System Icons (MIT). Company and school logos belong to their owners.
